KPIs

Calculated as in the analysis package (Spicker et al., 2026): ratios over the number of successful transfers. la = level of automation · ci = centrality index · rtci = real-time capability · mdi = media disruptions · fpyi = first pass yield.
Values are a working view; the Python analysis remains the reference for the thesis.

Export

All tables (CSV) and the JSON backup are packed into one ZIP file. On the iPad tap Share / save ZIP and choose Save to Files (e.g. a folder On My iPad) or AirDrop to your computer. The app itself sends nothing; only use share targets allowed by the data protection concept.
